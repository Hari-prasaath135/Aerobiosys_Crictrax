VICTORY MESSAGE LOGIC
═══════════════════════════════════════════════════════════════════════════

SCENARIO 1: Second Innings WINS (Score ≥ Target)
├─ Calculation: wickets_remaining = 10 - wickets_lost
├─ Example 1: Score 60, Target 50, Lost 3 wkts → 10-3 = 7 wickets
├─ Example 2: Score 85, Target 70, Lost 2 wkts → 10-2 = 8 wickets
└─ Message: "TeamB won by 7 wickets" ✅

SCENARIO 2: Second Innings LOSES (Score < Target)
├─ Calculation: runs_deficit = target_runs - actual_score
├─ Example 1: Target 50, Scored 45 → 50-45 = 5 runs
├─ Example 2: Target 85, Scored 70 → 85-70 = 15 runs
└─ Message: "TeamA won by 5 runs" ✅
