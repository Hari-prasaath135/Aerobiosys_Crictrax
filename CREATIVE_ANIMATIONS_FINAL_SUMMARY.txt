TECHNICAL ARCHITECTURE
================================================================================

BEFORE (❌ BROKEN):
   Lottie Package → JSON Files → Parse → Invalid Frames → CRASH

AFTER (✅ WORKING):
   Animation Classes → AnimationController → Native Flutter → Success

CLASS HIERARCHY:
   StatefulWidget
   ├── BoundaryFourAnimation (SingleTickerProviderStateMixin)
   ├── BoundarySixAnimation (TickerProviderStateMixin)
   ├── WicketAnimation (TickerProviderStateMixin)
   │   └── WicketPainter (CustomPainter)
   └── DuckAnimation (SingleTickerProviderStateMixin)

ANIMATION TRIGGERS:
   ├── addRuns(4) → _triggerBoundaryAnimation('4') → BoundaryFourAnimation
   ├── addRuns(6) → _triggerBoundaryAnimation('6') → BoundarySixAnimation
   ├── addWicket() → _triggerWicketAnimation() → WicketAnimation
   └── addWicket() + runs == 0 → _triggerDuckAnimation() → DuckAnimation

CUSTOMIZATION OPTIONS
================================================================================

All animations can be easily customized:

DURATION:
   Change Duration(milliseconds: 1200) to any value
   Example: Duration(milliseconds: 1500) for longer animation

COLORS:
   Change Color(0xFFHHGGBB) hex values
   Example: 0xFF9C27B0 for purple instead of green

SCALE:

   Add shadow/glow effects
   Change rotation speeds
   Modify easing curves
